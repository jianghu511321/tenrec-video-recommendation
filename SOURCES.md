# Source provenance

- Tenrec reference repository: [yuangh-x/2022-NIPS-Tenrec](https://github.com/yuangh-x/2022-NIPS-Tenrec), inspected at commit `a6c242da0dab9c547410e8fdcde611436931dea6`.
- DeepCTR-Torch reference repository: [shenweichen/DeepCTR-Torch](https://github.com/shenweichen/DeepCTR-Torch), inspected at commit `9eccef78e5810c61d6a04ddc7d96279e3db9c970` during earlier project work.
- Original SASRec research: [Self-Attentive Sequential Recommendation](https://arxiv.org/abs/1808.09781), Wang-Cheng Kang and Julian McAuley, 2018.
- Dataset: Tenrec's `sbr_data_1M.csv`, 1,120,679,998 bytes in the recorded local download. Obtain the data and accept the terms through the [official Tenrec portal](https://static.qblv.qq.com/qblv/h5/algo-frontend/tenrec_dataset.html).
- Tenrec's `gen_sbr.py` builds this derivative from QK-video click-positive rows, removes videos with fewer than two or more than 200,000 corpus clicks, and retains the first one million grouped user histories. The corpus-level preprocessing predates the experimental split used here.
- Runtime used for recorded experiments: Python 3.9.12, PyTorch 2.8.0+cpu, NumPy 1.26.4, SciPy 1.13.1, faiss-cpu 1.13.0. The local environment also contained pandas 2.2.3 and scikit-learn 1.6.1 from earlier experiments.
- Root-level Python scripts are the project's custom preprocessing, training, retrieval, and evaluation implementation. Local upstream snapshots under `vendor/` are excluded from publication. These scripts run using the dependencies in `requirements.txt`.
- Aggregate experiment outputs retain source-file metadata and cohort hashes for traceability. Dataset rows, encoded interaction cohorts, ID mappings, and model checkpoints remain local and can be regenerated by following the README.
